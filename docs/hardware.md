# Hardware

Este documento reúne informações sobre o hardware associado aos computadores comercializados pela Sunsix com Linux pré-instalado.

## Hardware conhecido

Registros históricos indicam que a Sunsix comercializou computadores com diferentes configurações de hardware, utilizando tanto plataformas Intel quanto AMD.

Entre as configurações encontradas estão:

* Processadores Intel Core 2 Duo
* Processadores AMD Athlon X2
* Processadores AMD Phenom X4
* Memória DDR2
* Discos rígidos SATA
* Rede Ethernet 10/100
* Áudio integrado
* Vídeo integrado em alguns modelos
* Unidades de CD/DVD

Registros mais antigos também indicam configurações com aproximadamente 256 MB de RAM e discos rígidos de 40 GB.

Isso indica que o Sunsix Linux não estava limitado a uma única configuração de hardware, mas era distribuído com diferentes modelos de computadores Sunsix.

## Compatibilidade

A mídia preservada utiliza arquitetura **i386 (32 bits)** e é baseada no Ubuntu 7.04, com kernel da série **Linux 2.6.20**.

Ainda não foi identificada evidência conclusiva de que a ISO tenha sido desenvolvida exclusivamente para um modelo específico de computador Sunsix.

Está sendo investigada a existência de:

* Drivers específicos para hardware Sunsix
* Módulos de kernel personalizados
* Scripts de detecção ou configuração de hardware
* Configurações específicas para determinados modelos
* Utilitários fornecidos pelo fabricante

## Pesquisa

O objetivo é identificar quais configurações de hardware eram originalmente fornecidas com o Sunsix Linux e determinar se a distribuição possuía alguma personalização específica para esses equipamentos.

Computadores Sunsix originais, CDs de drivers, manuais, fotografias, anúncios e outras mídias de instalação podem fornecer evidências adicionais.
