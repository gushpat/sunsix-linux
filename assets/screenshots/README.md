## 📷 Guia para Envio de Novas Capturas

Ao testar a ISO em máquina virtual ou hardware real, você pode contribuir enviando novas imagens!

### Padrão de Nomenclatura:
* **`boot_splash.png`:** Tela de carregamento inicial (Usplash).
* **`login_gdm.png`:** Tela de login (Gnome Display Manager).
* **`desktop_menu.png`:** Desktop com o menu de Aplicações expandido.
* **`ubiquity_installer.png`:** Instalador gráfico do sistema.
* **`terminal_fetch.png`:** Terminal exibindo `uname -a` e `cat /etc/lsb-release`.

### Requisitos Técnicos:
- Formato: PNG ou WebP.
- Resolução original da máquina virtual (sem escalonamento borrado).
- Não incluir barras de título ou molduras de hipervisores (crop na área de trabalho).
